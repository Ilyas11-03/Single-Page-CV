# Portfolio - Aboulkassim Ilyas

Bienvenue sur mon portfolio en ligne ! Ce site présente mon parcours professionnel, mes compétences et mes projets. Il sert également de CV interactif.

## 🌟 Aperçu

Ce portfolio a été conçu pour :
- Présenter mon parcours et mes compétences de manière attractive.
- Permettre aux recruteurs de consulter mon CV en ligne.
- Mettre en avant mes réalisations et projets personnels/professionnels.

## 🚀 Fonctionnalités

- **Page d'accueil** : Présentation concise avec un call-to-action.
- **CV en ligne** : Version interactive de mon CV avec expériences, formations et compétences.
- **Projets** : Galerie de mes travaux.
- **Contact** : Formulaire de contact et liens vers mes réseaux professionnels.
- **Responsive** : Compatible mobile, tablette et desktop.

## 🛠 Technologies utilisées

- **Frontend** : HTML5, CSS3, JavaScript
- **Style** : Tailwindcss
- **Animation** : AOS(Animate on Scroll Library) : https://michalsnik.github.io/aos/
- **Hébergement** : Vercel
